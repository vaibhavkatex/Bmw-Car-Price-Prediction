# 🚗 BMW Car Price Prediction using Machine Learning

A **Machine Learning Web Application** that predicts the **price of a BMW used car** using **Linear Regression**. The application is built with **Python**, **Scikit-Learn**, and **Streamlit**, providing a simple and interactive interface for users to estimate car prices based on vehicle specifications.

---

🌐 Running the Streamlit Application - https://bmwcarpriceprediction-uvhrm8k6ku9asbjtybmene.streamlit.app/

---

## 📌 Project Overview

This project demonstrates the complete Machine Learning workflow:

- Data Collection
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- One-Hot Encoding
- Feature Scaling
- Model Training using Linear Regression
- Model Evaluation (R² Score)
- Model Deployment using Streamlit

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/vaibhavkatex/BMW-Car-Price-Prediction.git
```

### 2️⃣ Navigate to the Project Folder

```bash
cd BMW-Car-Price-Prediction
```

### 3️⃣ Install Required Packages

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the Streamlit Application

```bash
streamlit run app.py
```
